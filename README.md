# EKG-Atlas Inhalt

Freigegebene Inhaltsaktualisierungen für den EKG-Atlas (Web und Android).

- `version.json`: aktuelle Version und SHA-256 der Inhaltsdatei
- `atlas-inhalt.json`: freigegebene Änderungen und Quellenstatus, wird bei jeder neuen Version überschrieben
- `AENDERUNGSLOG.txt`: fortlaufendes Änderungsprotokoll

Enthält nur Lerninhalt, keine personenbezogenen Daten. Änderungen werden ausschließlich vom Administrator freigegeben.
